# Store pi1 and pi2 values from the stan BSSD model in a dataframe.

Store pi1 and pi2 values from the stan BSSD model in a dataframe.

## Usage

``` r
# S3 method for class 'bssd_binary_map'
as.data.frame(x, row.names = NULL, optional = FALSE, ...)
```

## Arguments

- x:

  stanfit object.

- row.names:

  row names flag.

- optional:

  optional flag.

- ...:

  extra parameters are passed to [`stan_bssd`](stan_bssd.md).
